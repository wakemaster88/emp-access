# Archiv: einmalige Daten-Skripte

Skripte, die genau einmal fuer eine Datenkorrektur oder einen Import gelaufen
sind (Tristar-Import, Anfaengerkurs-Umstellung, Massen-Pause im Juni 2026 …).
Sie bleiben als Nachschlagewerk erhalten, sind aber nicht mehr fuer den
laufenden Betrieb gedacht und laufen gegen einen Datenstand, den es so nicht
mehr gibt. Vor einem erneuten Aufruf immer den Code lesen.

Die noch gebrauchten Werkzeuge liegen eine Ebene hoeher in `scripts/`.
